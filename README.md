# 🛒 BenforMarket - Sistema POS e Inventario

BenforMarket es un sistema web de Punto de Venta (POS) y Gestión de Inventario diseñado para optimizar el flujo de trabajo de un minimarket. 

## 🚀 Tecnologías utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS).
* **Arquitectura:** Diseño modular y responsivo.
* **Próximas integraciones:** Base de datos en Supabase (PostgreSQL) y Asistente de IA (Make + WhatsApp).

## 🔑 Funcionalidades Principales
1.  **Control de Acceso (RBAC):** Roles definidos para Administrador, Cajero y Encargado de Almacén.
2.  **Punto de Venta Dinámico:** Escaneo de productos, cálculo de cambio en efectivo y soporte para pagos con QR.
3.  **Gestión de Inventario:** Panel CRUD (Crear, Leer, Actualizar, Borrar) para productos con alertas visuales de stock bajo.
4.  **Dashboard Predictivo:** Panel gerencial que utiliza el modelo matemático $S(t) = s_0 - kt$ para predecir los días restantes antes del desabastecimiento de un producto.
